## Проект

- Учебный сайт по физике: главная, Учёба, Посты, Форум, Профиль.
- React 19 + TypeScript + Vite 8; Three.js для фона; Lucide для иконок.
- Рабочая папка: `work/Teren-main/Teren-main` относительно папки текущего чата.
- Backend приложения переведён с Firebase на Supabase. Файлы Firebase Hosting не означают использование Firebase Auth/Firestore. Не выводить содержимое `.env.local` или секреты в чат.
- 4 октября 2026 текущая версия опубликована на `https://terenphys.web.app` через Firebase Hosting. Supabase не используется для хостинга интерфейса: он обслуживает данные и вход. В `.env.production` указан этот публичный адрес; в Dashboard сохранены Site URL и три production Redirect URLs, девять локальных адресов сохранены.
- В рабочем дереве накоплены изменения предыдущих этапов. Не сбрасывать их и не публиковать/не делать push без запроса.
- GitHub: `https://github.com/Madiii55/TerenPhys.git`, основная ветка `main` отслеживает `origin/main`. 9 октября при подготовке обновления локальная ветка связана с существующей историей GitHub без перезаписи рабочих файлов. Старый индекс сохранён вне репозитория в `outputs/github-update/index-before-update` папки чата. Локальные `.env`, зависимости, сборка и `.firebase`-кэш исключены из Git; `.env.example` содержит только шаблоны. Для продолжения разработки не инициализировать репозиторий заново и не делать force push.
