# Письмо подтверждения TerenPhys

Применено и проверено 12 октября 2026 в существующем проекте `gotlcaqzrwfitgiwmsnj`.

`confirmation.html` — короткое письмо на русском и казахском без внешних картинок, шрифтов и пользовательских данных.

Для Authentication → Emails → Confirm sign up:

- Subject: `TerenPhys — подтверждение почты / Поштаны растау`.
- Body: содержимое `confirmation.html`.
- Ссылка: `{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email`.

Используется существующий обработчик `verifyOtp` сайта. Подтверждение не зависит от PKCE-данных браузера, в котором начата регистрация. Site URL — `https://terenphys.vercel.app` (сохранён и проверен 13 октября 2026 при переносе на Vercel); переменная автоматически направляет новые письма на этот адрес. Оригинальная ссылка одноразовая. В локальной проверке подставляются только фиктивные значения, настоящие токены в репозиторий не записываются.

SMTP-параметры для указанного пользователем отправителя:

| Поле | Значение |
|---|---|
| Sender email address | `TerenPhys@gmail.com` |
| Sender name | `TerenPhys` |
| Host | `smtp.gmail.com` |
| Port | `465` (SSL/TLS) |
| Username | `TerenPhys@gmail.com` |
| Password | Пароль приложения этого Google-аккаунта; вводится владельцем непосредственно в Dashboard |
| Minimum interval per user | `60` секунд |

Пароль Gmail/SMTP не хранить в клиенте, Git, HTML-шаблоне или чате. Владелец самостоятельно создал и сохранил пароль приложения непосредственно в Dashboard. Custom SMTP включён, Confirm Email обязателен. Шаблон и тема сохранены в Confirm sign up; после обновления страницы проверены русский/казахский текст, единственная кнопка и отсутствие старого английского письма.
