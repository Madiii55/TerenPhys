# Эйнштейн в TerenPhys

Эйнштейн — объёмный персонаж и помощник по физике. Текущий персонаж подготовлен из пользовательского `base.obj`; исходник сохранён в `model-source/einstein/`, готовый самостоятельный файл находится в `public/models/einstein.glb`. Модель получила текстуры цвета и шероховатости, мягкое сглаживание лица, неглубокие зрачки и настоящие веки. Персонаж моргает и поворачивает голову и взгляд к подсвеченной кнопке. Исходная поза с руками у карманов сохранена.

Справа внизу находится круглая кнопка с иконкой (52px на компьютере, 48px на узком экране). Она открывает компактный чат шириной до400px с маленьким Эйнштейном в шапке и индикатором текущей темы. Пустой чат занимает350px по высоте, переписка — до500px, гость видит короткое приглашение войти. Размер ограничен экраном; поле ввода остаётся доступным, переписка прокручивается отдельно. Постоянных навигационных карточек нет. В конспекте три короткие учебные подсказки только заполняют поле; запрос выполняется при отправке. Есть остановка ответа и очистка переписки с отдельным подтверждением. В закрытом состоянии персонаж размонтирован. Закрытие сохраняет переписку и черновик в памяти страницы. Есть Escape, возврат фокуса, русский и казахский интерфейсы.

Экспорт воспроизводится через `scripts/export-einstein.mjs` с инструментами из `scripts/model-tools/` — порядок описан в `model-source/einstein/README.md`. GLB занимает 1 537 180 байт и содержит 134 176 треугольников, включая все 120 000 исходных. Текстуры встроены; внешние платные сервисы для подготовки/отрисовки модели не нужны.

Окно знает открытую страницу, выбранные класс, четверть, раздел и версию конспекта. В нативном конспекте локально определяется фрагмент у места чтения: текст берётся из того же неизменяемого учебного JSX, а DOM используется только для координат заголовков и блоков. Фрагмент ограничен3500символами; большие разделы передаются частично. Иллюстрации не передаются как изображения. У открытого пробного СОРа/СОЧа модель знает только тип просмотра, содержимое файла не получает. По явному запросу о навигации ответ может предложить действие из заранее заданного списка: кнопка с глазом подсвечивает реальный элемент, обычная кнопка выполняет переход. ИИ не может исполнить JavaScript, указать произвольный селектор или открыть чужую ссылку.

В задачах по кинематике кнопка «Помощь Эйнштейна» открывает окно и подставляет публичное условие с просьбой сначала дать подсказку. Введённый учеником ответ не передаётся. Запрос выполняется после нажатия «Отправить вопрос».

## Бесплатный сервис

Используется Gemini Developer API и модель `gemini-2.5-flash`. В Supabase Edge Functions → Secrets владелец добавляет `GEMINI_API_KEY` из проекта Google AI Studio с тарифом Free Tier и без подключённой оплаты. OpenAI не используется, даже если `OPENAI_API_KEY` уже сохранён. Автоматического перехода на платную модель, повторных запросов при ошибке квоты и платных дополнительных инструментов нет.

Модель можно выбрать через `EINSTEIN_GEMINI_MODEL`, допустимы только `gemini-2.5-flash` и `gemini-2.5-flash-lite`. При исчерпании квоты интерфейс сохраняет вопрос для повторной отправки позже. Сервер сайта не меняет тариф проекта Google.

Документация: [ключ Gemini](https://ai.google.dev/gemini-api/docs/api-key), [тарифы](https://ai.google.dev/gemini-api/docs/pricing), [проверка Free Tier](https://ai.google.dev/gemini-api/docs/billing), [серверные секреты Supabase](https://supabase.com/docs/guides/functions/secrets).

## Сервер и приватность

Функция `einstein-assistant` требует JWT и дополнительно проверяет действующего пользователя через Supabase Auth. Нужна подтверждённая почта. Ключ Gemini хранится только в серверном окружении. Сервер передаёт Gemini текст вопроса, ограниченную историю беседы и публичный учебный контекст, включая ограниченный фрагмент выбранного нативного конспекта. Почта, профиль, черновики ответов, посты форума и содержимое всей страницы не отправляются. Чтение, прокрутка, открытие чата и заполнение поля не вызывают ИИ.

Переписка хранится только в памяти открытой страницы и очищается при смене аккаунта. Старый ответ не появляется после переключения аккаунта; смена страницы, раздела, языка или версии конспекта отменяет незавершённый запрос. Прокрутка сохраняет отправленный снимок фрагмента и не прерывает ответ. Старые действия не используются для нового раздела. Новый ответ открывается с начала, ручное чтение истории не прерывается. На бесплатном тарифе Google может использовать вопросы и ответы для улучшения своих продуктов; уведомление доступно в раскрытии «О данных и ответах» возле формы и в политике конфиденциальности. Остановка ответа не возвращает уже зарезервированный лимит.

В базе сохраняются только счётчики запросов: по умолчанию 5 в минуту и 20 в день для пользователя, 200 в день для сайта. Реальная бесплатная квота Google может быть меньше. Таблица в закрытой схеме `einstein_private` имеет RLS и недоступна клиентам. RPC `einstein_reserve_request` работает с правами вызывающего, доступен только серверной роли и резервирует лимиты в одной транзакции. Старые счётчики очищаются при последующих запросах; это не отдельное расписание удаления.
