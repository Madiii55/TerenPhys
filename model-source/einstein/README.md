# Исходная модель Эйнштейна

`base.obj` — оригинал модели пользователя, скопированный без изменений.
SHA-256: `1501194f54e0b4ff20d1b739b628b05aa7dbad4402245ca7049cac0268d3df08`.

Исходник содержит 60 002 вершины, 120 000 треугольников и UV-развёртку;
материалов и текстур в предоставленном OBJ не было.

Подготовка для сайта сохраняет все исходные треугольники, мягко сглаживает
неровности лица (максимальное смещение 0,00319 исходной единицы), запекает
цвет и шероховатость в исходные UV и добавляет неглубокие зрачки, веки
и кость головы. Исходная поза с руками у карманов сохраняется.

Повторить экспорт из корня проекта:

```powershell
npm.cmd ci --prefix scripts/model-tools --no-audit --no-fund
node --experimental-strip-types scripts/export-einstein.mjs
node --experimental-strip-types --test tests/einsteinModel.test.ts
```

Раскраска: `scripts/bake-einstein-texture.mjs`.
Сглаживание: `scripts/finish-einstein-geometry.mjs`.
Сборка персонажа и подготовка анимации: `scripts/prepare-einstein-model.mjs`.
Результат: `public/models/einstein.glb`; отчёт экспорта — в игнорируемом `build/`.

Инструменты экспорта устанавливаются отдельно от зависимостей сайта и
не загружаются пользователем. Исходный OBJ также не входит в публикацию.
